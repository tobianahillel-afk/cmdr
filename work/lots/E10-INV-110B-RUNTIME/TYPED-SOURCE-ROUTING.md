# E10-INV-110B — typed canonical linked-source authorization route (opt-in)

Source-backed choice: reuse the existing `AccessChecker` and `EntryResolver` interfaces, `AccessRequest` Case binding and Go standard library. The canonical permission register and A-CONTRACT require separate read permissions for Evidence (`perm.investigate.evidence.read`), Shared telemetry (`perm.shared-capabilities.telemetry-event.read`), Govern Decision (`perm.govern.decision.read`) and Command Incident (`perm.command.incident.read`). A generic `source-owner-read` is only a legacy engineering placeholder. No new global ACL database, invented schema, paid API, third-party policy engine or parser of caller-controlled `SourceRef` prefixes is needed.

New opt-in `ProjectFromOwnerSnapshotsWithTypedSources` requires **three trusted server-side dependencies**: Case/Timeline/source ACL checker; Timeline Entry owner snapshot resolver; and SourceOwnerResolver that maps a Case-bound source reference to an authoritative owner/type/object ID. Every resolved identity must match the selected Case, tenant, environment and original reference; unknown kind and malformed object IDs fail closed. All owner identities for allowed Timeline Entries are resolved before any source ACL dispatch; the typed ACL then checks one of the four canonical permissions. No access can come from `Entry.SourcePermission` or caller `Scope` flags. The legacy generic route remains unchanged as transitional compatibility, and must **not** be described as production-ready.

This code supplies the typed **contract and routing only**, not real authenticated provider implementations, consistency/ACL-revocation semantics, deployed transport or full CAP-INV-110 release. Tests use stub owner/checker/resolver; they are not proof of real provider integration. `OPEN-013` remains unresolved. Read full SHA-specific GitHub Actions results before marking CI green; no old performance samples are rebased to this change. An independent SHA-pinned L2 must evaluate this new authorization boundary before any promotion.
