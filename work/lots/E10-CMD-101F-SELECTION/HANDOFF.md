## Functional proof target

Previously it rendered only a list. Now optional selected=Incident:ID or selected=Task:ID selects ONLY an existing authorized row from the currently visible 50-row page, after all owner checks. Bad/repeated/overlong/control/invalid UTF-8 selector fails 400 before resolving host; nonexistent/foreign/denied/filtered/off-page selector yields indistinguishable generic 404. No additional provider calls or reads, no privilege transfer.
Same browser GET form contains a safe keyboard-friendly selection submit button per row with existing view/status/sort. Selected context displays only prior row fields, contextual HTML escaping; no new route, JavaScript, modal or Inspector. Six view links retain view filters/order, but drop stale selection. No selection preserves original JSON payload (omitempty) and legacy HTTP behavior.
