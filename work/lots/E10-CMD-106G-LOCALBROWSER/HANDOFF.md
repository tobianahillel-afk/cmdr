# E10-CMD-106G-LOCALBROWSER — livraison bornée et non-production

**Motif :** la PR #201 rendait une Timeline HTML filtrable, mais le routeur Command ↔ Investigate n'avait pas de point d'entrée exécutable hors tests. Les en-têtes Bearer injectés dans des tests httptest ne sont pas automatiquement portés par un vrai navigateur natif. Ce nouveau `cmd/local-browser` est un **exécutable local de démonstration**, pas une nouvelle source de vérité ni une production.

**Quatre propriétaires :** comportement pilote CAP-CMD-106 Command, consommateur CAP-CMD-101 Work Queue et destination CAP-INV-110 Investigate ; Timeline Entry et Object Linking restent Shared. Ingénierie : parent existant E10-CMD-106, enfant G dépend E10-CMD-106F-TIMELINE et E10-INV-110K-HTMLFILTER implémentés. Code : routeur existant `product-runtime/command-investigate-host`, nouvel exécutable isolé sous `cmd/local-browser/**`, imports des modules Go first-party existants. Git : base PR #201 SHA `dc714668f4e50deeb92057dc89a0c5911d104893`, DISTINCT du parent produit/ingénierie, SHA #201 gelé et intact.

**Parcours réellement utilisable :** lancer go run depuis le module host, prendre URL 127.0.0.1 et mot de passe temporaire analyst/commander, ouvrir la Work Queue en navigateur avec HTTP Basic généré (front-door uniquement), sélectionner Incident source autorisé, suivre href Case même origin via routeur existant, ouvrir HTML Case Timeline versionné, comparer statut `superseded`, filtrer/paginer par formulaire natif. L'authentification Basic synthétique vérifiée place uniquement un principal dans Context, chaque handler et chaque owner réévaluent indépendamment les droits ; le lecteur Command seul est refusé par Investigate. Deux owners séparés : relation Shared liée à Incident et statut Case Investigate ; aucune permission implicite transmise.

**Frontières / refus :** écoute seulement TCP4 loopback éphémère ; Host strict 127.0.0.1 ; génération crypto/rand 32 octets par rôle et comparaison constante ; aucune entrée de mot de passe dans URL, cookies, liens ; no-store, nosniff, no-referrer ; méthodes GET existantes uniquement. Aucun vrai IAM, SSO, cookie de production, TLS, source Wazuh externe, stockage ou audit durable, aucune mutation Class-2 (OPEN-013). Basic sur loopback est uniquement une fonction de démo, pas une proposition de mécanisme pour déploiement réseau.

**Preuves demandées :** tests HTTP réel avec httptest, test lançant le vrai listener `127.0.0.1:0`, navigation par Basic auth, Incident / Case autorisé, HTML filter, page de correction, séparation de comptes, host spoof refusé, arrêt par annulation, source JSON préservée ; Go/race/vet/gofmt/coverage et engineering-kernel tous vérifiés sur SHA GitHub exact. CI verte ne vaut ni review native ni fusion. Ne pas créer automatiquement de nouvelle L2 complète si revue incrémentale proportionnée suffit. Aucun statut ACCEPTED/production et aucun parent #201/#200/#199 ou PR antérieure réécrit.

## Correctif de démarrage et état de la preuve

La première révision du programme exécutable compilait sur les trois plateformes mais échouait aux **seuils de couverture obligatoires** du nouveau module : 81,5 %, puis 86,7 % de couverture changed-critical, sous le minimum 90 %. Ces anciens SHA ne sont pas recevables. La même branche conserve les seuils intacts et exerce effectivement les refus de session, périmètre, source, entropie cryptographique courte, mots de passe réutilisés, listener indisponible et console incapable d'afficher les identifiants. Une erreur d'affichage ferme désormais le listener avant de servir, changement fonctionnel de sécurité vérifié par un vrai socket. Le serveur s'arrête sur SIGINT/SIGTERM. La CI sur le SHA intermédiaire `6b4c3a3978d73c6dd1fbe59f242e1a0fa87cc26a` a mesuré **90,3 % sur cmd/local-browser** et **91,5 % sur les deux packages**, avec tests Linux, macOS et Windows ; ce résultat historique NE DOIT PAS être transféré au SHA actuel sans nouvelle CI. Le dernier SHA doit être vérifié via les Actions de la PR #202, les trois OS et engineering-kernel, avant gel de la version et planification éventuelle de L2 indépendante.
