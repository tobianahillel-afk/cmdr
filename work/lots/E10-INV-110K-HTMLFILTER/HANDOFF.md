# E10-INV-110K-HTMLFILTER — Real browser Case Timeline filtering

## Canonical user behavior
CAP-INV-110 §3,§11-12 explicitly requires a Case analyst to *filter* authorized Timeline. PR #200 provided static HTML reading and pagination on GET /case-timeline; it did not allow filter input in the browser. This distinct bounded increment adds an accessible no-JavaScript GET form with type (one of five already known kinds), authorized metadata search q, optional RFC3339 start (inclusive)/end (exclusive), page size 1..200, reset filter action and normalized selection preview. Typed source permissions and existing Project/read are unchanged; no Case mutation, new owner, route, query engine or source access.

## Four distinct owners
Product: Investigate CAP-INV-110 Case Timeline reads and filters; Shared owns Timeline Entry, typed owners authorize source fields; Command CAP-CMD-106 is only an existing cross-product entrypoint and never authorizes Case reads. Engineering: child K of **existing** E10-INV-110 epic, depends on E10-INV-110J-CASEHTML IMPLEMENTED, not full product ACCEPTED. Code: existing Go `case_html.go` / `case_http.go` with only presentation selection, and `case_html_test.go`. Git ancestry: exact base PR #200 SHA `12f92a24ee0d0be0b4bd298f7baef577f5fcdbaa`; original #200 and L2 SHA remain frozen and unmodified. A Git parent is not a product parent.

## Trust and data semantics
The HTML form action is fixed /case-timeline, GET, and hidden case_id is always extracted from the authenticated server owner read; no bearer, principal, tenant, environment or ACL values are sent. Empty browser optional controls kind/q/from/to are omitted only for Accept:text/html; malformed duplicate, unknown key, out-of-range/invalid time or oversized page still fails BEFORE any owner lookup. JSON API with empty filter remains 400. Form never forwards offset so a fresh search starts at page 1. Page links only reuse validated existing view selectors and reauthorize each request. CSP remains default-src 'none' with explicitly restricted same-origin form-action 'self', no JavaScript, html/template and URL query encoding for all untrusted selectors, no-store. Times with uncertainty remain in original visible presentation; query filters only authorized fields. A missing hidden/denied source remains denied regardless of client-side HTML options.

## Test, CI and release limits
New tests use existing real Go httptest handler with synthetic Case/Timeline/typed source owners: form workflow, selected kinds, q, from/to as optional, reset and next-page link, HTML escaping, cross-principal denial, invalid/duplicate selectors and strict unchanged JSON. All original runtime/Command integration tests must remain green on the final exact SHA. This is **not** a production browser with live enterprise IAM, persisted Timeline, external source connector, screenshot, authorized class-2 correction workflow or acceptance of whole CAP-INV-110. The independent L2 of prior #200 does not cover this new SHA; a separate short risk-based L2 may be warranted for changing CSP form-action and HTML parser normalization. PR remains Draft; required parent reviews/merge are not performed by CI.
