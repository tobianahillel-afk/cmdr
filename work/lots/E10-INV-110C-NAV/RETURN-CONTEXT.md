# E10-INV-110C-NAV — analyst return link (local synthetic journey)

## Functional increment
The existing Case Timeline source-navigation endpoint already returns a provider-neutral draft and a **presentation-only**, validated `return_query`. This increment connects that response to an explicit analyst action: copy a local `/analyst?... ` return link and restore Case, kind, query, UTC time window and page position after a browser reload. The analyst must enter the temporary bearer manually and submit before any data request. All Case/Timeline/source permissions are then recomputed server-side by the unchanged owner adapters.

Only an explicit click copies a URL; the app never places the bearer, a source destination ID or an authorization assertion in the link. An optional query/search term and Case selector can be sensitive metadata, so the UI warns that users must share only with authorized recipients. Browser persistence, cookies, external navigation, third-party routing, automatic fetch, schema changes and new runtime dependencies were deliberately rejected. Referrer-Policy:no-referrer remains in force. Every server destination draft is compared against exactly the selection the browser sent, before enabling the copy action; no external or browser-provided `return_url` is accepted.

## Technical choice and exclusions
Reuse first-party `navigation_http.go`, `parseTimelineReadSelection`, existing demo UI and browser built-in `URLSearchParams` / Clipboard. Compared with a new frontend router or signed navigation token, this is smaller, avoids a new trust root and does not falsely promote a presentation context into authority. The date restore path preserves the original RFC3339 values to avoid accidental chronology shifts during daylight-saving folds; DOM inputs are local presentation only.

Go tests cover a real authorized Case -> source draft -> local return URL -> unauthorized 401 -> authorized Case Timeline 200 cycle and absence of tokens in static HTML. Asset-level assertions cover explicit copy, same-origin local construction, query binding, no persistent credentials, cancellation and restoration. The real embedded analyst.js is now exercised under the first-party Node 24 vm harness for return restoration, explicit copy, tampered-return rejection and no automatic fetch. This is still not a real-browser accessibility/UI test; the in-memory, loopback-only Case owner and bearer are synthetic, not a production identity/persistence system. This is a C-NAV increment, **not** C-NAV VERIFIED, not full CAP-INV-110 delivery and not a production performance/SLO claim.

OPEN-013 and Shared Timeline Entry ownership remain unchanged. No cross-product route to a real Evidence/Telemetry/Govern/Command application is manufactured; that application must independently authorize on open.
