# Directions visuelles interdites

CMDR ne doit pas ressembler à :

- un HUD ou cockpit militaire ;
- une interface cyberpunk, futuriste ou néon ;
- une scène de hacking ;
- un jeu vidéo ;
- un écran bancaire ;
- un portail cloud générique ;
- une page marketing spectaculaire ;
- une mosaïque de grandes cartes saturées ;
- un tableau Excel brut ;
- un Kanban généralisé ;
- une interface métallique, chromée, 3D ou à halos ;
- un produit utilisant bouclier, cadenas géant ou symbole cyber générique comme identité principale.

Ces interdictions s’appliquent à tous les produits et thèmes.
