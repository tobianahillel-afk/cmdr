# Palette générale CMDR

| Token | Valeur |
|---|---|
| CMDR Ink | `#18201F` |
| CMDR Bone | `#F2EFE6` |
| CMDR Moss | `#8EA68F` |
| CMDR Ember | `#D7644B` |
| CMDR Fog | `#D7DDD7` |
| CMDR Graphite | `#4B5451` |
| CMDR Stone | `#C8C6BE` |

## Usage

Bone est le fond principal; Ink porte les titres; Graphite les informations secondaires; Stone et Fog les bordures; Moss exprime continuité et confiance; Ember reste un accent de marque ou d’engagement, jamais une couleur critique générique.
