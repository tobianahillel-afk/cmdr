# Règles d'usage Investigate

## Utiliser

- accent proposé uniquement dans les maquettes de comparaison ;
- provenance, annotation et relation comme motifs principaux ;
- thème clair et sombre à parité ;
- alternatives tabulaires aux graphes ;
- monospace ciblé ;
- séparation visuelle des niveaux de vérité.

## Ne pas utiliser

- une proposition de palette dans les tokens ;
- noir absolu ;
- bleu néon ou vert terminal ;
- graphe comme décoration ;
- plusieurs Inspectors ;
- Finding et suggestion IA avec le même statut ;
- texture « code » derrière les contenus.

## Marketing Investigate

Montrer profondeur et preuve par relation, annotation, timeline ou détail technique réel. Éviter le hacker, le malware imaginaire et la lueur bleue.
