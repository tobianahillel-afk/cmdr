# Propositions de palette Govern

## Statut

`OPEN-002` reste `open`. Les trois directions sont `proposed` et ne peuvent pas être consommées par les tokens de production.

## Direction A — Bronze Ledger

### Intention

Évoquer registre, conséquence et matérialité documentaire sans orange d'alerte ni luxe métallique.

| Rôle proposé | Valeur |
|---|---|
| Canvas clair | `#F0ECE3` |
| Surface claire | `#FAF8F2` |
| Canvas sombre | `#28241E` |
| Surface sombre | `#332E25` |
| Texte profond | `#29251F` |
| Accent principal | `#6B5738` |
| Accent secondaire | `#8B7450` |
| Seal / sélection douce | `#C7B995` |

- Accent sur canvas clair : environ 5.85:1.
- Texte profond sur canvas clair : environ 12.92:1.
- Différenciation non chromatique : règles de décision, conditions, blocs de signature.
- Risque : perception patrimoniale ou trop traditionnelle.
- Rejet si : le bronze devient métallique, luxueux ou proche d'un orange de warning.

## Direction B — Civic Aubergine

### Intention

Exprimer autorité civique et responsabilité humaine par une aubergine sourde, sans violet IA.

| Rôle proposé | Valeur |
|---|---|
| Canvas clair | `#F0EBEC` |
| Surface claire | `#FAF7F7` |
| Canvas sombre | `#292226` |
| Surface sombre | `#352B30` |
| Texte profond | `#292226` |
| Accent principal | `#634B56` |
| Accent secondaire | `#8A6C64` |
| Seal / sélection douce | `#C8B9BC` |

- Accent sur canvas clair : environ 6.66:1.
- Texte profond sur canvas clair : environ 13.17:1.
- Différenciation non chromatique : marges d'autorité, signatures, supersession.
- Risque : glissement vers luxe, juridique théâtral ou violet agentique.
- Rejet si : saturation élevée, gradient ou symbolique de pouvoir décorative.

## Direction C — Olive Charter

### Intention

Exprimer stabilité, condition et réversibilité par un olive institutionnel distinct du vert opérationnel Command.

| Rôle proposé | Valeur |
|---|---|
| Canvas clair | `#ECEDE5` |
| Surface claire | `#F8F8F3` |
| Canvas sombre | `#24281F` |
| Surface sombre | `#2E3328` |
| Texte profond | `#252820` |
| Accent principal | `#566044` |
| Accent secondaire | `#7A6B52` |
| Seal / sélection douce | `#C4C7B3` |

- Accent sur canvas clair : environ 5.65:1.
- Texte profond sur canvas clair : environ 12.70:1.
- Différenciation non chromatique : sections de charte, conditions, rollback.
- Risque : proximité avec Moss et Command.
- Rejet si : l'accent est lu comme succès ou disponibilité opérationnelle.

## Comparaison

| Critère | Bronze Ledger | Civic Aubergine | Olive Charter |
|---|---|---|---|
| Autorité calme | forte | forte | forte |
| Différence avec Command | forte | très forte | faible à moyenne |
| Risque de rouge/orange | moyen | faible | faible |
| Risque de violet IA | faible | moyen | faible |
| Chaleur éditoriale | forte | moyenne | moyenne |
| Dark theme | forte | forte | forte |

## Preuves nécessaires

- Action Request, Decision, Approval, policy, Response Run et rollback en clair/sombre ;
- tests de distinction avec sémantique warning/critical ;
- revue non punitive et non bureaucratique ;
- contraste et daltonisme ;
- validation sponsor.

## Interdiction de consommation

Aucune direction n'entre dans `product-theme-tokens.md` avant résolution d'OPEN-002.
