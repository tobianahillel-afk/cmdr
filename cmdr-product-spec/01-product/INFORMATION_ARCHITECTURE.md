# Information Architecture

## Top-level model

CMDR exposes three permanent console tabs:

1. **Command Center**
2. **Investigation Lab**
3. **Response & Governance**

The current console changes the information density, language and actions, but selected tenant, time context and active incident/case relationship remain available.

## Command Center navigation

Mission Control, Incident Detail, Work Queue, Intelligence, Exposure, Capabilities, Operational Timeline, Reports, System Health and Settings.

## Investigation Lab navigation

Triage Desk, Case Workspace, Case Timeline, Evidence Board, Event Search, Entity Graph, Hypotheses & Findings, Static Analysis, Dynamic Sandbox, Reverse Engineering, Debugger, Memory Forensics, Disk & Artifact Forensics and Investigation Report.

## Response & Governance navigation

Response Inbox, Action Center, Decision Register, Playbooks, Runs & Rollback, Policy Gates, Approvals & Authorities, Agent Fleet, Audit Trail and Response Metrics.

## Global surfaces

Global search, tenant/context selector, time range, notifications, task inbox, user profile, help, keyboard shortcuts and deep links are shared platform surfaces. Their canonical behaviour is documented outside console pages.

## Density principle

Each page must foreground the decisions appropriate to its console. Cross-console summaries are allowed; full duplicate workspaces are not.
