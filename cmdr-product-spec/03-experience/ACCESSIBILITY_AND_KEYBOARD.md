# Accessibility and Keyboard

## Target

CMDR targets WCAG 2.2 AA for core workflows.

## Requirements

- Full keyboard navigation with logical focus order and visible focus indicator.
- No rectangular browser-default focus around circular map markers; use shape-aware focus treatment.
- Status is never conveyed by colour alone.
- Charts and maps expose textual summaries and navigable data alternatives.
- Tables support headers, captions and screen-reader relationships.
- Live regions announce material updates without flooding users.
- Time, severity and confidence labels use understandable text.
- Zoom to 200% preserves workflows without horizontal page scrolling except for intentional canvases.
- Reduced motion, high contrast and theme preferences are respected.

## Keyboard model

Global search, command palette, help and console switching have discoverable shortcuts. Canvas-based evidence and entity graphs provide list alternatives and predictable arrow-key navigation.

## Acceptance

Critical workflows—acknowledge incident, create case, verify evidence, submit response request and decide request—are executable without a pointing device.
