# Workflows — Cases and Evidence

1. Incident, Signal ou Hunt → Case nouveau ou existant.
2. Case → Hypothesis → recherches ou collecte future → Evidence.
3. Artifact, Event ou result → candidate → qualification Evidence.
4. Evidence pour/contre → revue → Finding draft → confirmation humaine.
5. Finding → Action Request draft → Govern.
6. Govern Result → Case → Hypothesis, Finding ou next action.
7. Case → content package → Reporting Engine.
8. Case clôturé → replay/review → Task, Readiness ou Detection future.
