# Cases and Evidence

## Mission

Organiser l’investigation dans un Case, tester des Hypotheses, relier des Entities et Artifacts, qualifier Evidence, produire Findings, conserver Timeline et collaboration, puis préparer Govern et Reporting.

## Capabilities

`CAP-INV-101` à `CAP-INV-114`.

## Shared Capabilities

| Shared Capability | Usage Investigate | Données locales | Source canonique |
|---|---|---|---|
| Saved Views | Case Queue | vues système futures | Shared |
| Comments/Notes/Presence | collaboration | contenu Case-scoped | Shared |
| Attachments | usage proposé | qualification et liens | OPEN-014 / Shared |
| Timeline Engine | ordre et interaction | événements analytiques | Shared |
| Trace/Activity Stream | audit | business events | Shared |
| Reporting Engine | draft/review/publish | contenu et citations | Shared |
| Inspector/Context Bar | inspection/context | configuration locale | Design System |
| Object Linking | relations | reason/type | Shared |

## Limites

Les objets complets, permissions atomiques, stockage Evidence, custody technique, workflows Govern et écrans détaillés restent ultérieurs.
