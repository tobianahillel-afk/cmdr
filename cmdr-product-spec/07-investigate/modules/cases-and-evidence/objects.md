# Objets — Cases and Evidence

Possédés : Case, Hypothesis, Artifact, Evidence, Finding.

Consommés : Incident, Task, Signal, Event, Entity, Action Request, Decision, Response Run, Result, Automation Run et Report.

Ouverts : Hunt, Attachment, Note, Comment, Timeline Event, Report et Audit/Provenance records selon leurs registres et sources partagées.

`Action Request` est Govern lifecycle ; Investigate produit et complète. `Attachment` n’est ni Artifact ni Evidence sans qualification.
