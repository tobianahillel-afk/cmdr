# Tuning, suppressions and exceptions

CAP-INV-429 creates evidence-backed tuning proposals that return to a new Draft. CAP-INV-430 creates bounded suppression/exception proposals with scope, expiry, alternatives, compensating monitoring and revocation.

Proposal ≠ active change. Suppression never deletes historical Signals. Exception is not a permanent bypass. Application, renewal and revocation require Govern.
