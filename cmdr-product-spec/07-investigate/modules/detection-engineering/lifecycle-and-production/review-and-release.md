# Review and release

CAP-INV-418 turns a Review Package into an explicit immutable Release Candidate. CAP-INV-419 assesses readiness per target. CAP-INV-420 prepares the Govern handoff. Review passed is not Approval; readiness is not deployment.

A candidate must preserve authoring evidence, unresolved gaps, owner, reviewers, target conditions, rollback and provenance. Returned-for-changes always points to the source Draft/version.
