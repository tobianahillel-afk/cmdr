# Review and Release

CAP-INV-527 verifies analytical coherence, source support, provenance, confidence, alternatives, sensitive data, audience, markings, releasability and separation of duties. Quality-passed is not Govern Approval. A Release Recommendation is a versioned analytical disposition, never publication or transmission.
