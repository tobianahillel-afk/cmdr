# Watchlists and Operationalization

CAP-INV-530 defines watchlist purpose, Indicators, scope, duration, restrictions, lifecycle and activation handoff. Investigate never activates the watchlist; `active-observed` is a runtime-owner projection. CAP-INV-531 prepares an Indicator Operationalization Package toward Detection Engineering, Command or Settings. The package is not a rule, active watchlist, deployed Indicator, block or Signal.
