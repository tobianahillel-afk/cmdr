# User questions

- Is the source complete, partial, corrupted, encrypted, restricted or unsupported?
- Which acquisition, custody, copies, transformations and limitations apply?
- Which partitions, volumes and filesystems are candidates, and why?
- Which interpretation was selected, by whom and with what confidence?
- Which entries, files, links, metadata and relationships are observable?
- What is active, deleted-candidate, unallocated, residual, recovered-candidate or inaccessible?
- Which journal records exist and what cannot be inferred from them?
- Which system, configuration, user and application observations are persistent rather than current state?
- Which startup or execution artifacts are persistence candidates, and what contradicts them?
- Which timestamps are observed, recorded, reconstructed, estimated or absent?
- Which recovery outputs are partial or unattributed?
- Which content is encrypted, compressed or restricted, and what authorized next step exists?
- What differs between images, volumes or snapshots?
- Can the analysis be reproduced?
- What may be handed to Evidence, Findings, Static, Reverse, Memory or future phases?
