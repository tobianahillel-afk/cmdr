# User questions

- What Artifact and version am I examining, and where did it come from?
- Which architecture, format, Tools and environment are compatible?
- What is observed, proposed, inferred or confirmed by an analyst?
- Where am I in address, offset, function and reference space?
- How do disassembly and decompilation relate, and where do they disagree?
- Which callers, callees, data references, paths and structures are unresolved?
- Which annotation or rename came from whom, from which source and with what confidence?
- How do two versions differ, and which preconditions limit the comparison?
- Is the Debugger Session isolated, authorized and distinct from a real Endpoint?
- Which breakpoint or control event caused the current runtime state?
- Which thread, frame, value, region, module or exception is actually available?
- Can an isolated experiment be reverted without changing the original?
- Can the analysis be reproduced with the same Tool, version, environment and inputs?
- What can be prepared for Evidence, Findings or future Detection Engineering without automatic qualification?
