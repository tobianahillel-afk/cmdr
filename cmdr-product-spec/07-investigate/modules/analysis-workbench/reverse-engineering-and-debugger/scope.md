# Scope

## Included
Reverse intake and sessions; binary navigation; disassembly; decompilation; functions, symbols and xrefs; control/call/data-flow analysis; types and structures; annotations and renaming; binary diffing; isolated debugger sessions; breakpoints and functional execution control; runtime state, threads, stacks, debugger-scoped memory/modules; debug events; reversible isolated experiments; provenance; Evidence/Finding/future Detection Engineering handoff.

## Excluded
Memory Forensics, Disk/Filesystem Forensics, advanced Network Forensics, Cloud or Mobile analysis, exploit or payload creation, bypass/evasion techniques, real commands, engine selection, implementation, real Endpoint debugging, production patching, detailed screens and atomic permissions.

## Boundary rule
Any action aimed at a real target is unavailable here and must transition to the owner capability and Govern. Phase 4B.2B.3 and Phase 4B.3 remain not started.
