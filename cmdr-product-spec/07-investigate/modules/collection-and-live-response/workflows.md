# Workflows

1. Case → Endpoint Context → Collection Request → Collection Job → Artifact → Evidence qualification.
2. Case → Endpoint Context → Live Session → Endpoint Operation → Operation Result → Artifact/Case.
3. Finding → CAP-INV-215 → CAP-INV-113 → Govern Decision → Response Run → Result → Case.
4. Offline Endpoint → queued/awaiting-reconnect when policy permits → expiry/cancel/retry without duplicate execution.
5. Automation proposal → human accept/modify/reject → explicit launch; no autonomous sensitive action.
