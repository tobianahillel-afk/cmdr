# Workflows — Signals and Hunt

1. Signal → inspecter → qualifier → pivoter ou lier au Case.
2. Question → Query authoring → validation → exécution → inspection.
3. Résultats → organiser → Hunt ou Case.
4. Hunt → queries/runs → Hypotheses → conclusion → Case.
5. Toute activité → événements métier → Trace/Activity Stream.

Chaque workflow reste utilisable sans IA.
