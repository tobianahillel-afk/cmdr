# Cloud Analysis automation and AI

## Permitted assistance
AI or deterministic automation may propose scope, relevant services, resource groups, identity relations, permission paths, event summaries, anomaly candidates, correlations, Hypotheses, Evidence Candidate/Finding Draft content and Detection Engineering packages.

## Prohibitions
No permission grant, Cloud mutation, secret use, unauthorized reveal, automatic human attribution, exploit confirmation, automatic misconfiguration/vulnerability/Finding/Evidence confirmation, rule creation, response execution or trace deletion.

## Attribution
Every automated output records initiator, producer/agent/model and version, Tools, Tool Calls, Automation Run, sources, parameters, timestamp, status, errors, uncertainty and human accept/modify/reject disposition.

## No-AI path
Viewers, tables, trees, graphs with tabular alternatives, timelines, filters, search, comparators, deterministic parsers, explainable rules, checklists, non-agentic workflows and human review cover every essential capability.
