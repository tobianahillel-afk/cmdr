# Governance

This domain defines how the CMDR product specification is maintained and interpreted.

## Canonical documents

- `SOURCE_OF_TRUTH.md` — precedence, ownership and anti-duplication rules.
- `DOCUMENT_LIFECYCLE.md` — statuses, review cadence and change process.
- `OWNERSHIP_AND_RACI.md` — functional ownership by domain.
- `DECISION_LOG.md` — durable architectural and product decisions.

No console page may locally redefine shared entities, states, permissions, design tokens or transition contracts.
