# Source Material

## Purpose

This directory records authoritative sponsor decisions, constraints, preferences and unresolved decisions. It is an input layer and does not replace canonical product, UX, object, permission, screen or implementation specifications.

## Precedence

1. Current master product brief and later explicit sponsor decisions.
2. Approved ADRs.
3. Validated canonical specifications.
4. Draft canonical specifications.
5. Proposals and assumptions.

A conflict is resolved in the higher-precedence source and recorded in the traceability matrix. Two active definitions are not retained.
