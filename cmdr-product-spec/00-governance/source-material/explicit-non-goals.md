# Explicit Non-goals

## Product non-goals

CMDR is not defined as a simple SIEM, EDR, SOAR, ticketing tool, chatbot, agent orchestrator, vendor aggregator, security dashboard or third-party wrapper.

## Experience non-goals

- no tool-list information architecture;
- no cyberpunk, military HUD or game aesthetic;
- no page for every filter;
- no duplicate Work Queue in every product;
- no product-specific competing Inspector;
- no AI-only essential workflow;
- no uncontrolled panel stacking.

## Current phase non-goals

Phase 0 does not decide final network protocol, binary format, certificate format, signature algorithm, microservice architecture, database, messaging system, production framework, kernel driver, final CPU budget, infrastructure sizing or deployment architecture.

## Documentation non-goals

The program does not create text solely to fill files, convert proposals into decisions, mark documents validated automatically, hide missing decisions behind abstract text or claim planned capabilities are implemented.
