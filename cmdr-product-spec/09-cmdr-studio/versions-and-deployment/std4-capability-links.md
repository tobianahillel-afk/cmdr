# Versions & Deployment — STD-4 Capability Links

Publishing/release/deployment/lifecycle contracts are `CAP-STD-061..067`, with provenance/closure in `CAP-STD-068`. Existing version/deployment/rollback sources remain active historical sources. Normative STD-4 terminology distinguishes **Studio Deployment Reversion** from **Govern Response Rollback**; Endpoint technical update/rollback remains Endpoint-owned.
