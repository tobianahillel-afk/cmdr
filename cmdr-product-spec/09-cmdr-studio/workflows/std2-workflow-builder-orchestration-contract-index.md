# STD-2 Workflow Builder & Orchestration Contract Index

Parent: Delivery Roadmap Phase 5 — Studio and Endpoint. `STD-2` is an execution lot only.

- `CAP-STD-017..021`: definition, Builder, I/O/variables, graph, Tool/Skill step composition.
- `CAP-STD-022..025`: deterministic conditions/branches, mappings, subworkflows, ordering/parallelism.
- `CAP-STD-026..029`: errors, retry/idempotency, partial/compensation, Human Gate/Govern boundary.
- `CAP-STD-030..033`: validation/readiness, Workflow Version, pre-publish lifecycle, provenance/cross-product.

STD-2 defines no Automation Run lifecycle, runtime scheduler, Control Room behavior, publishing/deployment engine, Endpoint capability, API, protocol, orchestration language or detailed screen UI.
