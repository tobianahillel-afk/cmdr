# Investigation Lab

## Mission

Investigation Lab is the evidence-led workspace for triage, case management, event exploration, forensic analysis, hypothesis testing, findings and reproducible reporting.

## Boundaries

The Lab establishes facts and recommendations. It does not silently alter operational incident truth or bypass response governance. Specialist analysis capabilities remain distinct while sharing provenance and case context.

## Pages

Triage Desk, Case Workspace, Case Timeline, Evidence Board, Event Search, Entity Graph, Hypotheses & Findings, Static Malware Analysis, Dynamic Sandbox, Reverse Engineering, Debugger, Memory Forensics, Disk & Artifact Forensics and Investigation Report.
