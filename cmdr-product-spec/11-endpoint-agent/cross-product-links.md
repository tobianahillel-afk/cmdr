# Endpoint EPT-1 Cross-Product Links

## Platform Settings
Settings owns Endpoint Agent Fleet, enrollment administration, Endpoint Policy/assignment, Fleet selectors, upgrade waves, tenant/environment administration, providers/integrations, credentials and raw secrets. Endpoint supplies individual technical projections only.

## Studio
Endpoint Agent != Automation Agent. Endpoint technical capability != Studio Tool. Endpoint technical execution != Tool Call/Automation Run. Studio Deployment != Endpoint update primitive.

## Govern
Technical state/output != canonical Result. Endpoint execution != Response Run. Local rollback primitive != Govern response rollback. EPT-1 creates no production-response authority.

## Investigate
Endpoint facts may be consumed as investigation context, but they do not become Evidence or Finding automatically and Endpoint does not own Case/Artifact/Evidence/Finding.

## Command
Command may display authorized health/freshness/capability projections but retains Incident/Alert/Signal/Task ownership and does not own the Agent.

## Shared
Jobs, Trace, Activity, Search, Reporting, Export, Notifications, Versioning and generic Recovery remain Shared. Local Audit Event != Shared Trace.

Every handoff preserves tenant/environment, source, freshness, permission and return origin.
