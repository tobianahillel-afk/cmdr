# EPT-4 Automation and AI Model

AI is optional. Essential Collection and Live Response paths remain manual/deterministic.

AI may propose a bounded collection scope, summarize collected technical output, explain collection/execution failures, summarize command output and suggest a next diagnostic action.

AI may never authorize collection, open a session autonomously, execute an effectful command/script outside authority, fabricate bytes/output, invent Result/Evidence, qualify Artifact/Evidence automatically, bypass Govern, reveal raw secrets, hide partial collection, delete provenance or claim timeout means confirmed target termination.

Deterministic alternatives: capability/policy matrices, bounded forms/plans, state reconciliation, completeness diffs, error catalogues, raw output/transcript views, explicit operator controls and owner-specific handoff workflows.

Automation provenance retains initiator, producer/version, Tool Call/Automation Run refs when applicable, source request, target, bounds, authority refs, output/status, human disposition and correlation.
