# Exemples de placement IA

Autorisé : suggestion inline attribuée, aide à la requête, hypothèse proposée, résumé avec sources, Automation Tray fermé, trace Studio.

Interdit : chat global obligatoire, bouton Ask AI répété, avatar, étoile, gradient violet, contenu généré indiscernable d'un fait, action risquée exécutée depuis une suggestion.

Sans provider, les chemins manuels, règles, recherche et outils déterministes restent disponibles.
