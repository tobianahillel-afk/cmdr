# Anti-patterns d’interface

- plusieurs actions primary dans une même région ;
- dashboard de cartes remplaçant une table ;
- panneaux sans min/max ;
- Inspector local concurrent ;
- modal contenant un workspace ;
- Work Queue divisée en pages ;
- statut uniquement coloré ;
- console empilée ;
- refresh complet après live update ;
- thème sombre cyberpunk ;
- palettes proposées consommées comme actives ;
- contrôle critique par icône seule.
