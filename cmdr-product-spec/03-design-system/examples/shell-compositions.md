# Compositions de shells

| Activité | Shell | Régions |
|---|---|---|
| Work Queue | Queue | Header, Context Bar, Saved Views, filters, table, Inspector |
| Case | Case | context, internal nav, Evidence/Timeline, Inspector |
| Reverse | Technical Workbench | explorer, tabs, canvas, Inspector, console |
| Decision | Decision | request, evidence, impact, conditions, authority, trace |
| Response | Run | phase, targets, operations, results, rollback |
| Workflow | Builder | library, node canvas, Inspector, validation, output |
| Fleet | Settings | admin nav, table/form, detail, audit |

Aucune composition n'est une maquette finale.
