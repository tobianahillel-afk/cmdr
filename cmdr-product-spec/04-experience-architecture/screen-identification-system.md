# Identification des écrans


Format `<PRODUCT>-<MODULE>-<NNN>` avec `CMD`, `INV`, `GOV`, `STD`, `SET`. L'identifiant désigne une Page/Workspace durable, pas une Saved View.

Les IDs legacy d'une vue Work Queue deviennent aliases de migration vers le workspace et son `view` paramètre. Aucun nouvel ID n'est créé en Phase 3 pour les vues.
