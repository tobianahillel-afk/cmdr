# Onboarding

Le first-run vérifie tenant, environnement, rôle et préférences essentielles, puis conduit vers l'activité autorisée. Les empty states expliquent cause, prochaine action et source d'aide. Les raccourcis sont découverts dans le contexte, pas dans un tour imposé.

Les admins reçoivent un guided setup progressif pour tenant, sources et flotte ; les analystes découvrent Queue, recherche et Inspector ; Studio révèle Builder après permissions. Un tour peut être ignoré et repris. Aucun assistant IA n'est requis.
