# Aide et guidage

L'aide contextuelle relie terme, objet, action et documentation canonique. Les niveaux sont : microcopy immédiate, tooltip pour précision, aide inline pour décision, panneau d'aide pour procédure, documentation complète pour référence.

Une aide n'utilise pas le marketing, ne masque pas une permission et ne promet pas une capability `planned`. Le glossaire, les raccourcis et les messages d'erreur restent accessibles sans IA. Les pop-ups répétitifs et tours obligatoires sont interdits.
